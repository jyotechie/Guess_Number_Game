# Guess the Number Game

A simple interactive number guessing game built using HTML, CSS, and JavaScript.

## How to Play

1. The computer randomly selects a number between 1 and 10.
2. Enter your guess in the input box.
3. Click the **GUESS** button.
4. The game tells you whether your guess is:
   -  Correct
   -  Too High
   -  Too Low

## Features
- Random number generation
- Interactive user input
- Instant feedback
- Simple and clean game interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
